# 成长档案 H5 交互原型

手机优先的家长端设计，包含首页、成绩、意向和我的四个入口。支持多学生档案、新增与编辑考试、动态科目、分数或等级录入、意向学校维护、得分率趋势与可比总分统计。

这是前端交互原型，未连接认证、数据库或管理员服务。初始数据全部为虚构示例，用户填写内容仅保存在浏览器 localStorage，请勿用于正式采集。

本地预览：在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，访问 http://127.0.0.1:4173。

页面采用无依赖 HTML/CSS/JavaScript；部署目录为 dist。

## 管理员端

访问 `/admin/`，使用体验账号 `admin`、密码 `demo123`。包括管理员登录、概览、家长与学生、成绩记录、意向学校和汇总分析。支持手机号/学校/当前年级组合筛选、分页、只读详情和 CSV 导出（全部筛选结果，非仅当前分页）。CSV 包含 UTF-8 BOM 与公式注入防护，可用 Excel 打开。

管理员页独立使用虚构示例数据，不读取家长端本地填报。登录仅为浏览器会话中的演示，不具备生产认证或权限保障；真实管理员账号、服务端授权、数据库与 Excel 工作簿导出需后续接入。
