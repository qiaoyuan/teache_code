# 成绩记录与招生意向采集系统开发设计文档

版本：V1.11
日期：2026年10月14日

用途：供程序员或 AI 直接实施、联调和验收。

## 1 项目目标与实施依据

建设手机优先的家长填报端和管理员后台。家长管理本人名下的学生档案、考试成绩与意向学校，管理员查看全量数据、筛选、导出，并在家长忘记密码时重置密码。填报长期开放。

本文汇总《梳理成绩与招生意向需求》《选择适合后端的前端方案》《完善 .com 和 .cn 域名》三条聊天的结论，作为项目统一开发依据。冲突以用户最后明确确认的决定为准，并同步修改本文及《AI开发指令.md》；助手提出的方案不自动扩大业务范围。标记为“已确认”的规则来自用户决定；标记为“实施默认”的细节作为首版开发依据，可直接实施。

### 1.1 已确认规则

| 项目 | 最终规则 |
| --- | --- |
| 家长登录 | 手机号和密码 |
| 忘记密码 | 管理员在后台重置，不接短信找回 |
| 密码重置 | 使用临时密码，下次登录强制修改，并记录重置日志 |
| 学生数量 | 一个家长可以管理多个学生 |
| 成绩类型 | 每科分数或等级二选一，可在同批考试中混合使用 |
| 成绩比较 | 以单科比较为主 |
| 意向等级 | 仅“优先”和“备选” |
| 信息修改 | 家长自行修改本人名下的数据 |
| 管理员权限 | 全局查看、导出、重置家长密码，不代填或修改学生业务数据 |
| 学校名称 | 当前就读学校、意向学校自由输入；已被录取学校使用指定九项下拉 |
| 填报时间 | 一直开放，不设截止日期 |
| 后端框架 | Laravel，使用 PHP 开发 |
| 域名偏好 | 优先 `.com` 或 `.cn`，具体域名待上线前选定 |
| 页面入口 | `/app/` 为家长 H5，`/admin/` 为管理员后台，同一个 Laravel 项目 |

### 1.2 实施默认

- 注册不发送短信，手机号唯一；不保证注册者拥有该手机号。
- 学生档案保存当前年级；每次考试独立保存考试时年级。
- 科目提供常用选项，也允许自定义；同批内科目不能重复。
- 等级提供 A、B、C、D 快捷选项，允许自定义，不设统一分值或排序。
- 家长可以删除学生、考试及意向。业务删除采用软删除，删除学生时其考试、成绩和意向一并不可见且退出统计。
- 同一学生同一意向学校仅保留一条有效记录，通过编辑调整。
- 导出为 Excel `.xlsx`，包含全部符合条件的数据，不限当前分页。
- 单批全分数制考试可显示合计；混合考试只显示“分数科目合计”；首版不做跨考试平均总分或最高总分比较。

### 1.3 首版不包含

短信验证、手机号验证、短信登录、自动密码找回、招生录取办理流程（仅记录已被录取学校）、成绩审核、学校账号、通知群发、家长账号合并、批量导入、删除恢复界面、多级管理员权限、班级管理、学籍异动和 IM。

## 2 现有原型与正式开发范围

家长端预览：https://parent-growth-h5.tastyant3.chatgpt.site/  
后台预览：https://parent-growth-h5.tastyant3.chatgpt.site/admin/

源码位置为 `parent-h5/dist/`，管理员页位于 `parent-h5/dist/admin/`。可复用配色、布局、组件和表单交互。预览站点的访问控制不等同于本系统的家长或管理员认证。

正式前端按 Vue 3 组件实现，现有静态原型用于视觉和交互参考，不以原型的无框架实现限制正式选型。项目目录名称为 `teacher`，业务范围仍以本文为准。

现有页面使用示例数据、localStorage 和浏览器演示会话，不具有正式数据库、认证或后端授权。正式开发须替换这些实现，不得把演示账号 `admin / demo123` 用作生产凭据。

原型需同步调整：

1. 意向选项统一为“优先、备选”，去掉“了解中”等旧值。
2. 家长成绩概览改为单科分析，去掉跨考试平均总分、最高总分卡片。
3. 新增注册、手机号密码登录、修改密码及强制改密页。
4. 后台新增按家长账号组织的家长列表和密码重置入口。
5. 自定义等级、考试时年级、软删除接入真实数据模型。
6. CSV 演示导出替换为正式 Excel 导出。
7. 两端连接同一数据库，正式环境默认空数据；示例数据仅供开发环境使用。

## 3 页面与交互设计

### 3.1 视觉与布局

沿用米白背景、深绿色主色、浅绿色强调色。家长端按手机竖屏设计，底部导航为首页、成绩、意向、我的；后台以电脑表格工作区为主，左侧导航，并兼容手机菜单与表格横向滚动。

表单保存按钮在长页面中保持易于触达。保存期间禁用重复提交，失败时保留输入，成功后更新列表和统计。删除、重置密码需要明确确认。没有数据时提供填写入口，不显示假数据或错误的 0 分。

### 3.2 家长端页面

| 路径 | 页面 | 内容与操作 |
| --- | --- | --- |
| `/app/login` | 登录 | 手机号、密码、登录、注册入口、忘记密码说明 |
| `/app/register` | 注册 | 手机号、密码、确认密码、默认未选中的协议同意框；未同意不可注册 |
| `/app/agreement` | 用户协议与隐私政策 | 无需登录可阅读全文；最近更新日期 2026年10月13日，联系电话 18117988868 |
| `/app/change-password` | 修改密码 | 普通改密和重置后强制改密 |
| `/app/` | 首页 | 当前学生、学生切换、录入成绩、学生档案、最近考试、意向摘要 |
| `/app/students/new` | 新增学生 | 基本资料、已被录取学校（选填），保存后选中此学生 |
| `/app/students/:id/edit` | 编辑档案 | 修改资料、删除学生 |
| `/app/students/:id/exams` | 考试列表 | 按日期倒序，详情、编辑、新增、删除 |
| `/app/students/:id/exams/new` | 新增考试 | 名称、日期、考试时年级、备注、动态科目行 |
| `/app/exams/:id` | 考试详情 | 每科分数或等级、备注、分数科目合计 |
| `/app/exams/:id/edit` | 编辑考试 | 修改考试和全部科目，一次提交 |
| `/app/students/:id/analysis` | 单科分析 | 选择科目，查看趋势、最好成绩、等级分布 |

家长前端路由统一以 `/app/` 为前缀，管理员以 `/admin/` 为前缀。访问站点根路径 `/` 跳转至 `/app/`；两端未登录时分别跳转 `/app/login` 和 `/admin/login`。路径必须支持直接打开和刷新。前端已选学生仅为界面状态，不作为权限依据。

首次注册且无学生时，引导创建学生。创建后直接提供“录入成绩”和“填写意向”两个入口。切换孩子后，考试、图表和意向同步切换。最后一个学生被删除后回到空状态，不保留失效的学生选择。

家长端顶部“当前学生”栏仅用于切换学生，不显示右侧“＋ 添加”入口；新增学生通过“我的”中的“添加学生”或首页无学生时的引导入口进入。

“忘记密码”显示“请联系管理员重置密码”。联系方式由部署配置提供，未配置时不展示虚构号码，不自动拨号或提交工单。

### 3.3 考试录入

1. 确认学生，填写考试名称、考试日期和考试时年级。
2. 默认提供语文、数学、英语三个可编辑科目行；可增加或删除，至少保留一科。
3. 每科选择“分数”或“等级”。分数模式只填写“分数”，不填写满分；等级填写等级标签。
4. 切换类型时清除另一类型字段，防止混存。
5. 点击保存，一次性校验并提交考试和全部科目。

同一天可以有多个考试。修改学生当前年级或学校，不自动改写历史考试的年级或学校快照。编辑旧考试时也不自动刷新这些快照，家长可明确修正。

### 3.4 管理员页面

| 路径 | 页面 | 内容与操作 |
| --- | --- | --- |
| `/admin/login` | 管理员登录 | 独立管理员账号和密码 |
| `/admin/` | 数据概览 | 家长数、学生数、考试批次数、科目成绩条数、有效意向数 |
| `/admin/parents` | 家长列表 | 每行一个家长，手机号、注册时间、学生数、学生详情、重置密码、授权登录家长前台（仅查看） |
| `/admin/students` | 学生列表 | 每行一个学生，关联家长、档案、考试及意向 |
| `/admin/scores` | 成绩记录 | 每行一条科目成绩，组合筛选、考试详情、导出 |
| `/admin/intents` | 意向记录 | 学校、优先或备选、学生、家长、备注、导出 |
| `/admin/analysis` | 汇总分析 | 各科平均分、等级分布、意向学校及等级汇总 |
| `/admin/audit-logs` | 重置日志 | 操作人、家长账号、操作时间和结果，无密码内容 |

学生及意向列表按家长手机号、当前就读学校、当前年级筛选。成绩列表按家长手机号、考试时学校、考试时年级筛选，表单标签明确显示“考试时”。手机号支持部分匹配，学校支持关键词匹配，年级为枚举；多个条件以 AND 组合。

学校汇总仅对规范化后名称相同的记录合并，不自动识别学校别名。单科汇总允许按考试时学校和年级筛选；仪表盘默认全量，避免被误解为能力排名。

## 4 账号认证与权限

### 4.1 账号规则

- 家长手机号：大陆 11 位手机号格式，去除首尾空格后唯一。
- 家长密码：8～64 位，至少包含字母与数字；不去除或截断密码字符。
- 注册再次确认密码，并必须主动勾选“我已阅读并同意《用户协议与隐私政策》”。支持弹窗阅读，返回不丢失表单；后台同样校验同意及当前协议版本。协议正文按用户提供的八节内容展示；注册前提示监护人身份或授权。管理员账号由初始化命令创建，不提供公开注册。
- 管理员用户名、初始密码通过环境配置或交互输入提供，初始化不覆盖已存在账号密码。
- 密码只存安全哈希，使用 Laravel Hash 提供的 Bcrypt 或 Argon2 实现；默认 Bcrypt，禁止静默截断密码。采用 Bcrypt 时新增 72 字节上限校验，字符数与字节数限制在两端明确提示；不自行设计加密。[Laravel 密码哈希文档](https://laravel.com/docs/13.x/hashing)
- 登出、普通改密及管理员重置后，应按下述规则撤销旧会话。

### 4.2 会话与错误响应

实施默认采用服务端会话，Cookie 设置 HttpOnly，生产环境设置 Secure，SameSite=Lax，并对修改类请求校验 CSRF。家长会话与管理员会话使用不同 Cookie 名称或不同会话命名空间，避免两端登录互相覆盖。不得将登录凭据存入 localStorage。

在 Laravel 中分别配置 parent、admin 两个认证 guard 和对应 provider，分别关联 ParentAccount、Administrator 模型（parents、administrators 表）。角色身份、强制改密、auth_version 校验由服务端中间件执行。两端会话隔离须通过 Cookie/会话配置落实，不能仅靠 guard 名称；任一端登出不得意外撤销另一端会话。登录与改密成功后重新生成当前端会话标识。[Laravel 认证文档](https://laravel.com/docs/13.x/authentication)

| 情况 | 页面行为 | 接口响应 |
| --- | --- | --- |
| 未登录 | 跳转对应角色登录页 | 401 |
| 已登录但角色或资源权限不符 | 无权限提示 | 403 |
| 资源不存在或已删除 | 不存在提示 | 404 |
| 字段不合法 | 保留输入并定位错误 | 400 |
| 手机号或意向记录重复 | 提示重复原因 | 409 |
| 登录失败 | 统一提示账号或密码错误 | 401 |
| 登录频率超限 | 提示稍后重试 | 429 |

普通登录返回跳转地址必须限制为本站相对路径，防止跳转到外部站点。V1.8 授权登录跨域跳转仅使用服务端配置的家长 APP_URL，不接受客户端提供的跳转目标。

### 4.3 数据隔离

家长访问学生时校验所属家长 ID；访问考试、科目和意向时沿关联关系校验学生归属。列表查询从当前家长开始过滤。请求中的 parent_id、role 等字段不能改变归属或提升权限。

创建考试与意向时，后端从已验证的学生推导家长归属。管理员接口逐个校验管理员身份，不因知道接口地址而放行。家长对其他家长现存资源的访问必须返回 403，包括读取、编辑和删除。

### 4.4 管理员重置密码

1. 管理员按手机号找到家长账号，打开确认弹窗，显示手机号和关联学生摘要。
2. 管理员设置符合密码规则的临时密码，二次输入确认后提交。
3. 服务端保存临时密码哈希、设置 `must_change_password=true`，递增账号会话版本，令该家长所有旧会话失效。
4. 同一事务写入操作日志，不记录临时密码、密码哈希或请求正文中的密码。
5. 管理员通过现有联系方式把临时密码告知家长；首版不自动发送消息。
6. 家长用临时密码登录后只能修改密码、登出或读取必要会话信息，其他业务接口返回 403，错误码 `PASSWORD_CHANGE_REQUIRED`。
7. 新密码不得与当前临时密码相同。修改成功后取消强制改密标记，撤销其他会话并重新建立当前会话。

原密码不可查看或找回。管理员不得通过重置入口代登录家长账号；授权查看使用独立授权入口，详见 V1.8。

## 5 数据模型

关系：家长一对多学生；学生一对多考试；考试一对多科目成绩；学生一对多意向。管理员与家长使用独立账号模型。

统一约定：业务表 ID 统一使用自增整数主键并位于表的第一个字段；created_at、updated_at、deleted_at 使用 DATETIME，时间值存 UTC，界面按 Asia/Shanghai 显示；考试日期为 DATE，不能因时区转换改变日期。数值成绩采用精确小数，显示最多两位；统计计算保留精度，仅在输出时舍入。

本文字段类型表示逻辑模型。MySQL 业务主键为 `BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY`，业务外键为 `BIGINT UNSIGNED`，模型采用默认整数自增主键，API 返回数字 ID；上述 DATETIME 字段通过迁移创建并由 Laravel 维护，数据库连接与应用存储时区统一为 UTC。使用 InnoDB、utf8mb4，金额式浮点计算不能替代成绩的 DECIMAL 精度。

### 5.1 家长 parents

`id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY`、唯一 `phone VARCHAR(11)`、`password VARCHAR(255)`（仅存 Laravel Hash 哈希）、`must_change_password BOOLEAN`（默认 false）、`auth_version INTEGER`（默认 1）、可空 `agreement_version VARCHAR(32)`、可空 `agreement_accepted_at DATETIME`、创建和更新时间。注册记录服务端当前版本与 UTC 同意时间；历史账号保留 NULL，不补造同意记录。

首版不提供删除家长账号或修改登录手机号。学生联系手机号独立于账号手机号。模型为 `ParentAccount`。

### 5.2 管理员 administrators

`id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY`、唯一 `username VARCHAR(64)`、`password VARCHAR(255)`（哈希）、创建和更新时间。模型为 `Administrator`。通过 `php artisan admin:init` 和 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 初始化，重复运行不覆盖已有密码。

### 5.3 学生 students

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| id / parent_id | BIGINT UNSIGNED | id 为自增主键，parent_id 为家长外键 |
| name | VARCHAR(50) | 必填，不作为唯一标识 |
| gender | VARCHAR(12) | male、female、unspecified |
| school | VARCHAR(160) | 必填，学校全称，提示 xx区（县）xx学校 |
| admitted_school | VARCHAR(160) NULL | 已被录取学校，固定九项单选，选填，可清空；旧记录 NULL |
| entry_year | SMALLINT NULL | 历史值保留，新页面不再填写 |
| entry_grade / current_grade | VARCHAR(3) | 入学年级可空；当前年级为班级下拉选择，必填 |
| class_number | SMALLINT UNSIGNED NULL | 班号，新建/编辑时必填，仅 1–99 的整数；旧记录 NULL |
| contact_phone | VARCHAR(11) | 中国大陆手机号 |
| created_at / updated_at / deleted_at | DATETIME | deleted_at 可空 |

年级枚举为 P1～P6、J1～J3、S1～S3，不从入学年份自动推算年级。软删除学生保留底层历史行，查询、统计和导出统一排除已删除祖先，保证其全部关联业务记录不可见。

### 5.4 考试 exams

`id`、`student_id`、`title VARCHAR(100)`、`exam_date DATE`、`grade_at_exam VARCHAR(3)`、`school_at_exam VARCHAR(160)`、`note TEXT`（请求最多 2000 字）、`version INTEGER`（默认 1）、创建/更新/删除时间。

日期不能晚于上海当天。学校由服务端自动从档案带入，无需填写；年级默认带入但可选择。编辑时保留原学校快照，不随学生档案变化。

### 5.5 科目成绩 exam_subjects

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| id / exam_id | BIGINT UNSIGNED | id 为自增主键，exam_id 为考试外键 |
| name / subject_key | VARCHAR(80) | 显示名称与规范化匹配键 |
| mode | VARCHAR(5) | score 或 grade |
| score | DECIMAL(7,2) | 分数制必填，等级制为空 |
| max_score | DECIMAL(7,2) NULL | 仅保留历史数据；新保存的科目为 NULL，不再采集或参与统计 |
| grade | VARCHAR(30) | 等级制必填，分数制为空 |
| position | SMALLINT | 科目行顺序 |
| active_subject_key | VARCHAR(80) | 有效记录生成键，删除后为 NULL |
| created_at / updated_at / deleted_at | DATETIME | deleted_at 可空 |

`0 <= score <= 10000`，最多两位小数；单次考试 1～50 科。禁止类型混用。同批有效科目的 `(exam_id, active_subject_key)` 有唯一约束。

文本采用 Unicode NFKC、首尾去空格、连续空白折叠；科目匹配键、学校匹配键与等级标签的拉丁字母转大写。显示名称保留规范化文字，不做语义或别名合并。

### 5.6 意向 intentions

`id`、`student_id`、`school VARCHAR(160)`、`school_key VARCHAR(160)`、`level VARCHAR(6)`（first/backup）、`note TEXT`（最多 2000 字）、`active_school_key`（有效记录生成键）、创建/更新/删除时间。

有效记录 `(student_id, active_school_key)` 唯一；删除后的键为 NULL。同名意向删除后可重新创建，多个不同学校可以同时标为优先。

MySQL 的规范化键、有效生成键及等级标签使用 `utf8mb4_bin` 比较，避免数据库默认排序规则额外合并名称。考试更新在事务中软删除旧科目、按提交顺序重建科目，不接受外部科目 ID。

### 5.7 日志 audit_logs 与会话 sessions

日志 id 为首列自增主键，created_at 为 DATETIME NOT NULL；不新增日志更新/删除时间字段。日志字段为 `id`、`admin_id`、`action`、可空 `target_id`、`ip_address`、`details JSON`、`created_at`。密码重置动作值为 `parent_password_reset`，导出为 `data_export`。日志包含操作对象、导出筛选条件与行数，不包含密码、Cookie 或 Token。管理员界面只读。

会话使用 Laravel 数据库 session，家长 Cookie 为 `growth_parent_session`，后台为 `growth_admin_session`。两个 Cookie 均 HttpOnly、SameSite=Lax；生产启用 Secure。角色会话配置在 StartSession 之前执行，不能仅以 guard 名称当作隔离。

session 的 user_id 为整数，另有 portal（parent/admin）标识。重置/改密仅删除 portal=parent 且 user_id 匹配的会话，避免两张账号表自增 ID 重叠时影响管理员。会话主键、缓存键和任务批次标识保留 Laravel 默认随机/文本键，业务表不再使用 UUID。字段顺序与 DATETIME 升级由新增迁移执行，转换期间显式使用 UTC，保留原始时间和 NULL。框架 jobs/job_batches 的 created_at 继续使用 Unix 秒数以兼容队列。升级旧库通过新增迁移映射所有主键、外键和审计目标，保留软删除数据，撤销旧会话；执行前备份并进入维护模式，失败时从备份完整恢复。

索引覆盖学生 parent_id、考试 student_id/exam_date、科目与意向的有效唯一键、session 的 portal/user_id 组合和 last_activity。数据库连接时区设为 `+00:00`。

## 6 接口设计

前缀 `/api/v1`。请求及响应使用 JSON。分页列表使用 Laravel 格式 `{data, total, current_page, last_page, per_page, ...}`，默认 20 条，上限 100 条。本人学生和意向是小列表，返回 `{data: [...]}`。单条业务返回 `{data: {...}}`，认证返回 `{user, csrf_token?}`。排序需稳定，日期相同追加 ID 排序。错误格式为 `{error: {code, message, fields?}}`。

Laravel Form Request 的校验响应需统一到本节约定及第 4.2 节状态码，前端请求明确接受 JSON。未登录接口不返回 HTML 登录页。跨家长访问现存资源按 403 处理，不能由默认路由模型绑定或过滤自动变成 404；确实不存在或已删除的资源返回 404。

### 6.1 家长接口

## 7 统计与单科比较

### 7.1 家长单科分析

选择学生与科目后，仅查询有效考试和有效科目。分数制与等级制分别显示，不连接在同一条数值曲线上。

- 趋势统一按录入分数展示，单位“分”，纵轴随数据范围调整，支持 0 分及超过 100 分的成绩。
- 平均分为有效分数记录的算术平均，最高分为有效分数记录的最大值；等级记录不参与。
- 不再计算或展示满分与得分率；历史记录也按原分数展示，不据此认定不同试卷下的能力高低。
- 趋势按考试日期升序排列，同日按创建时间及 ID 排序。横轴或提示中保留考试名称。
- 等级按规范化标签计数，不宣称 A、优秀或其他自定义标签等价，不换算为分数。
- 没有分数记录时隐藏数值曲线，显示空状态；只有一条时展示单点。
- 保存、编辑和删除后重新请求分析，不保留过期统计。

### 7.2 管理员统计

| 指标 | 口径 |
| --- | --- |
| 注册家长数 | parents 数量，不包含管理员 |
| 在册学生数 | 有效学生数量 |
| 考试批次数 | 有效学生名下有效考试数量 |
| 科目成绩条数 | 有效学生、考试及科目成绩数量，包含分数和等级 |
| 有效意向数 | 关联有效学生且未删除的意向记录数，无审核状态或截止状态 |
| 各科平均分 | 分数制记录按科目分组后的算术平均，单位为分 |
| 等级分布 | 按科目和等级标签分组计数 |
| 意向学校汇总 | 同学校 key 按学生去重，分别统计优先和备选 |

所有聚合在服务端计算，不能只对当前分页计算。学校自由输入导致的别名拆分不做自动修正。

### 7.3 用于验收的算例

同一学生三次语文成绩为 80、90、120：趋势为 80、90、120 分，平均分为 96.67，最高分为 120。统计反映录入数值，不代表不同试卷下的能力排名。

同一学生科学成绩为 A、A、优秀：分布为 A 两条、优秀一条，不计算平均等级。

同批语文 90 分、数学 80 分、科学 A：显示“分数科目合计 170”，不得显示完整考试总分，也不得把 A 当作 0 分。

## 8 Excel 导出

使用真实 `.xlsx` 文件，不以改扩展名的 CSV 代替。手机号、ID、年份和用户文本按适当的文本单元格写入，禁止将用户输入解释为公式。文件名含数据类型及导出日期，表头固定、中文可读。

| 工作表 | 主要字段 |
| --- | --- |
| 学生档案 | 学生ID、学生姓名、性别、学校全称、班级、联系手机号、注册家长手机号、考试批次数、意向数、已被录取学校 |
| 科目成绩 | 家长ID、账号手机号、学生ID、姓名、考试ID、考试名称、考试日期、考试时学校、考试时年级、科目、类型、分数、等级、考试备注 |
| 意向学校 | 家长ID、账号手机号、学生ID、姓名、当前学校、当前年级、意向学校、优先或备选、备注、更新时间 |

全量导出生成包含三张表的一个工作簿；单类导出生成对应工作表。all 全量工作簿的三张表均按注册家长手机号升序、学生姓名升序、记录 ID 升序排列，使相同手机号、相同姓名的记录连续；排序在数据库分批读取前完成。单类导出和后台列表保持原有排序。已删除数据不导出。分数制的等级留空，等级制的分数留空。导出接口必须校验管理员身份。

## 9 实现架构与交付

采用 Laravel 模块化单体应用：一个 PHP 后端、MySQL 数据库、家长和管理员两个 Vue 前端入口，前后端同域部署。后端提供 JSON API，并负责最终权限、校验、统计和导出。

项目内部划分为家长 app 与管理 admin，两端共享 Laravel 服务层、数据模型与数据库。正式代码布局如下；现有 `parent-h5` 保留为原型参考。

```text
teacher/
├── app/                         Laravel 后端代码
│   ├── Http/Controllers/
│   │   ├── ParentPortal/        家长端控制器
│   │   └── Admin/               后台控制器
│   ├── Http/Requests/
│   │   ├── ParentPortal/        家长端请求校验
│   │   └── Admin/               后台请求校验
│   ├── Models/                  共享数据模型
│   ├── Services/
│   │   ├── ParentPortal/        家长档案、成绩及意向业务
│   │   ├── Admin/               后台查询、密码重置及导出业务
│   │   └── Shared/              公共统计、规范化及会话撤销逻辑
│   └── Policies/                数据权限
├── resources/
│   ├── js/
│   │   ├── app/                 家长 H5 的 Vue 入口、路由和页面
│   │   ├── admin/               后台的 Vue 入口、路由和页面
│   │   └── shared/              通用类型、组件与请求工具
│   └── views/
│       ├── app.blade.php        家长前端入口模板
│       └── admin.blade.php      后台前端入口模板
├── routes/
│   ├── web.php                  /app 与 /admin 页面入口
│   └── api.php                  /api/v1/app 与 /api/v1/admin 接口
├── database/migrations/
├── public/                      Nginx 网站根目录及构建资源
├── docs/
└── parent-h5/                   已有静态原型
```

家长 app 指页面和前端模块名称，Laravel 根目录 `app/` 仍用于后端 PHP 类。两份入口分别构建，不把后台页面模块打入家长端包；共享模块只放通用内容，权限仍由后端执行。


| 层次 | 选型与约束 |
| --- | --- |
| 后端 | Laravel；实施默认版本基线为 Laravel 13、PHP 8.4 |
| 数据库 | MySQL，InnoDB、utf8mb4；具体受支持版本在部署前锁定 |
| ORM 与迁移 | Laravel Eloquent 与数据库迁移 |
| 前端 | Vue 3、TypeScript、Vite，Composition API 和 script setup |
| 后台组件 | Element Plus，统一列表、分页、表单、弹窗与错误反馈 |
| 家长 H5 | Vue 3 复用原型样式，手机优先；不强行套用桌面后台布局 |
| 图表 | 可沿用 SVG 或选用兼容的图表库，保持第 7 节统计口径 |
| Excel | PHP 工作簿库生成真实 xlsx，锁定兼容依赖 |
| 部署 | LNMP，Nginx 提供前端静态资源并将 API 请求交给 PHP-FPM |
| 实时通信 | 首版不接入；未来新增 IM 时再评估 Laravel Reverb 或独立服务 |

Laravel 13 的版本支持范围包含 PHP 8.4。实施时校验服务器、扩展及 Composer 依赖兼容性，并提交 Composer 与前端包管理器锁文件；环境不满足时先说明差异，不自行换回其他后端框架。[Laravel 版本支持说明](https://laravel.com/docs/13.x/releases)

家长端与后台都必须实现 PHP MVC 与业务逻辑层。页面 URL `/admin/` 对应后台功能入口，后台 PHP 代码位于 Laravel 的 `app/Http/Controllers/Admin/`、`app/Http/Requests/Admin/` 和 `app/Services/Admin/`；不是仅创建一个 Vue 后台目录。

| 分层 | 职责 | 后台示例 |
| --- | --- | --- |
| 路由与中间件 | 分发请求，验证角色、会话版本、CSRF 及限流 | admin guard 与管理员中间件 |
| Controller | 接收已校验请求，调用 Service，返回统一 JSON 或下载响应 | ParentController、ScoreController、ExportController |
| Form Request | 字段格式、筛选参数及密码确认校验 | ResetParentPasswordRequest、ScoreFilterRequest |
| Service | 编排业务、查询、事务、密码重置、审计及导出 | ParentPasswordService、ScoreQueryService、ExportService |
| Policy | 对身份和资源操作作最终授权 | StudentPolicy、ExamPolicy |
| Model | Eloquent 模型、关联、精确字段类型与有效记录查询范围 | Parent、Admin、Student、Exam、ExamSubject、Intention |
| View | Vue 页面展示与输入交互，Blade 加载入口 | resources/js/admin 与 admin.blade.php |

家长业务对应 ParentPortal 下的 Controller、Request、Service；数据模型与确实相同的规则共用。后台重置密码通过 Admin Service 执行哈希更新、会话撤销和审计事务，不调用家长端修改接口绕过授权。公共统计等提取到 Shared，避免两端算法不一致。

Controller 保持简洁，不集中堆放业务规则；Service 不依赖 Vue 状态或直接读取 HTTP Request，而接收已校验参数和明确的当前操作者。事务由业务 Service 管理，Model 不承担请求分发或页面拼接。服务端分页、筛选、统计和导出不转移到前端。

Nginx 网站根目录指向 Laravel `public/`，请求交由 Laravel 按 `/app/`、`/admin/` 和 `/api/` 分发。两份 Vue 入口通过各自 Blade 模板加载 Vite 构建资源；页面深层路径刷新返回对应模板，API 不进入前端回退，未知 API 返回 JSON 404。前端构建后交付静态产物，首版不要求 Node 常驻服务；会话、缓存等可先使用数据库等适配驱动，不把 Redis、队列或 WebSocket 作为上线前置依赖。

生产域名采用 www 家长端、admin 后台，根域跳转 www；DNS、证书及服务器配置在上线时完成，预览站点域名不作为生产域名。环境配置统一管理应用 URL、可信来源、Cookie 和 HTTPS 参数，不在源码写死域名。

本地数据库连接参数已由用户指定，密码为空：

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=shengxue360
DB_USERNAME=root
DB_PASSWORD=
```

项目根目录 `.env` 保存本地连接参数，`.env.example` 提供配置模板；创建 Laravel 应用后将其合并到实际应用的环境配置，不覆盖应用密钥和其他配置。数据库连接及迁移在后端接入阶段验证，文档中的参数不代表已经创建数据库或执行迁移。

### 9.2 运行与安全要求

生产环境启用 HTTPS。登录失败按账号和 IP 进行短时间限流，返回统一错误信息；避免账号永久锁死。输入长度和数值范围在服务端校验，页面转义用户文本。日志不记录密码、Cookie 或完整敏感请求体。

管理员和家长认证边界、资源归属校验、强制改密限制不能依赖前端。修改操作使用数据库事务。数据库每日备份，上线前演练一次恢复；生产密钥和数据库凭据不提交到仓库。

初期无正式并发性能指标，但列表必须分页，导出不可静默截断。建立适当索引；数据量增大导致同步导出超时后再引入异步导出任务。

## V1.8 管理员授权登录家长前台

- `/admin/parents` 每行新增“授权登录”，已登录管理员点击后直接在新窗口打开配置 `APP_URL` 下的 `/app/authorized-login`，不再弹窗确认或要求再次输入密码。正式环境 `APP_URL=https://www.shengxue360.com`，不需要放宽双域名 Nginx 隔离或 Cookie 域。
- 此功能按既有管理员权限默认仅查看，不能代填、修改或删除学生、考试、意向，也不能修改家长密码；页面隐藏写入口，服务端统一返回 `403 / AUTHORIZED_READ_ONLY`。可查看本人目标家长名下资料，跨家长仍返回 403。
- 后台 `POST /api/v1/admin/parents/{id}/authorize-login` 无需提交密码，校验 admin 会话、CSRF 并限流。使用 64 位随机凭证，服务端以 SHA-256 摘要作为缓存键，1 分钟有效；`POST /api/v1/app/auth/authorized-login` 原子消费一次，保留家长端 CSRF 校验。凭证放在 URL fragment，进入页面立即清除，不进入查询参数、localStorage 或审计日志。
- 两域名须共享同一应用数据库、APP_KEY 和支持锁的缓存（生产使用现有 database 缓存）。无需新增数据表或迁移。授权会话最长 30 分钟，每次请求检查目标家长和操作者的 auth_version；任一账号改密后授权失效。
- 授权进入重新生成家长会话，仅切换当前浏览器的家长身份；后台登录与家长其他设备不受影响。家长前台持续显示目标手机号、操作者、仅查看状态、到期时间和“退出授权查看”。退出仅销毁该家长端会话。
- 授权查看可读取待强制改密账号的业务资料，但不解除 must_change_password 标记；家长本人正常登录仍须改密。家长使用自己的密码重新登录后清除授权状态，恢复正常家长权限。
- 操作日志记录签发、成功进入和主动退出：`parent_authorization_issued`、`parent_authorization_started`、`parent_authorization_ended`，包含管理员、目标家长、时间、IP 和只读标识，不记录任何密码或凭证。
