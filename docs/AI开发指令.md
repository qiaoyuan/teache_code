```text

先读取仓库指令、开发设计文档 V1.6 及现有源码。文档已汇总《梳理成绩与招生意向需求》《选择适合后端的前端方案》《完善 .com 和 .cn 域名》三条聊天。冲突以用户最后明确确认的决定为准；文档优先于旧需求和演示页面。实施默认可直接采用，不必逐项询问。若发现真正阻碍实现的冲突，说明具体问题，其余工作继续推进。

核心规则：
1. 家长手机号加密码注册登录，不接短信，也不接自动密码找回。注册必选用户协议与隐私政策，校验当前版本并记录服务端同意时间；历史账号不得补造同意。协议日期 2026年10月13日，联系电话 18117988868；注销和撤回申请目前通过电话人工处理。

3. 家长只管理本人名下的多个学生；管理员全局查看、筛选、导出以及重置家长密码，不修改学生、考试或意向。

10. 导出真实 Excel 工作簿，支持全量和全部筛选结果，不限当前分页。

后端已确定为 Laravel。采用 Laravel + MySQL + Vue 3 + TypeScript + Vite，后台使用 Element Plus；家长 H5 保留原型的手机布局与配色，用 Vue 组件重建。实施默认版本基线为 Laravel 13、PHP 8.4；校验实际运行环境和依赖后锁定版本，不自行改用其他后端框架。

同一个 Laravel 项目内划分家长 app 与后台 admin：页面入口 `/app/` 和 `/admin/`；接口前缀 `/api/v1/app` 和 `/api/v1/admin`；Vue 源码分别放 `resources/js/app/`、`resources/js/admin/`，共用模块放 `resources/js/shared/`。Laravel 根目录 app/ 保留其后端类用途。站点根路径跳转 /app/，两端独立登录与页面回退。

两端均必须实现 PHP MVC 和独立业务逻辑层，不能只交付 Vue 页面。后台 PHP 分别放 app/Http/Controllers/Admin、app/Http/Requests/Admin、app/Services/Admin；家长端对应 ParentPortal 目录。Model 放 app/Models 共享，公共统计及会话撤销规则放 app/Services/Shared。Controller 接收请求并调用 Service；Service 负责业务与事务，Policy 与中间件负责授权；Vue 负责视图。密码重置、审计、分页筛选、统计和 Excel 导出都必须由 PHP 执行。

部署沿用 LNMP，前后端同域，Nginx 提供构建后的前端静态资源，API 由 PHP-FPM 执行。家长和管理员使用独立身份模型、认证 guard 和隔离会话；采用 Laravel Hash 和服务端权限中间件，严格满足设计文档的状态码、密码字节长度和会话撤销规则。MySQL 的软删除有效记录唯一性须由数据库约束保证，不能只做前端或应用层预检查。

生产域名优先 .com 或 .cn，具体名称待上线前确定，不写死预览域名。班级管理、学籍异动和 IM 未纳入首版，不为其新增页面、数据表或实时通信基础设施。

本地数据库使用 MySQL：主机 127.0.0.1，端口 3306，数据库 shengxue360，用户名 root，密码为空。读取根目录 .env，将数据库参数合并到 Laravel 应用配置，保留应用密钥与其他配置。本地 .env 不提交版本库。后端接入时实际验证连接、数据库存在性和迁移，不将配置文件存在视为连接已成功。

按以下顺序完成：账号与权限、业务数据接口、家长页面、管理员列表及重置密码、统计图表及 Excel、测试与部署说明。不要停留在静态原型或只写开发计划。

必须验证越权访问、旧会话撤销、强制改密、非法及混合成绩、事务保存、跨满分统计、软删除、导出跨页完整和手机号文本格式。

交付源码、迁移、管理员初始化命令、锁定依赖、无真实凭据的配置示例、运行部署与备份恢复说明。对未完成内容和未验证的结果如实说明。
```

主键约定：7 张业务表 id 统一为 BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY，外键为同类型整数，API 的 ID 返回数字，不使用 HasUuids。手机号保持字符串。数据库 session 增加 portal，以 portal + user_id 撤销家长会话，不能因管理员 ID 与家长 ID 重叠而删除后台会话。已有 UUID 库通过新增迁移保留数据升级，先备份、维护；框架会话、缓存与批次标识保留默认类型。

id 必须位于业务表首列；created_at、updated_at、deleted_at（存在时）统一使用 DATETIME，UTC 存储，由 Laravel 维护时间，不设数据库自动更新。保留 NULL 和软删除语义。已有库通过新增迁移调整字段顺序和类型，不能修改历史时间值。框架队列时间继续保留 Unix 秒数。

## V1.7 管理员账号管理

- 后台新增 `/admin/administrators` 页面，支持分页查看管理员、新增账号和修改自己或其他管理员密码。继续使用单一 admin 角色，所有管理员权限相同；本次不增加删除、禁用或角色分级。
- 新建账号为 3–64 位 ASCII 字母/数字/下划线/点/短横线，以字母或数字开头，统一转小写并防止重名。密码沿用 8–64 位、含字母和数字、UTF-8 不超过 72 字节规则，需确认密码。
- 新增和改密均验证操作者当前密码并限流；仅后台已登录用户可访问，家长无法使用。保存密码哈希，不返回明文或哈希。
- `administrators.auth_version` 为 unsigned integer，默认 0，以新增迁移保留现有账号及密码。改密递增版本并按 portal=admin、user_id 清除目标会话，拦截旧版本会话；修改自己密码后退出并重新登录，不影响同数字 ID 的家长会话。
- 审计记录操作者、目标账号、IP、时间；不记录密码。新增接口：GET/POST `/api/v1/admin/administrators`，POST `/api/v1/admin/administrators/{id}/password`。
- 升级需先执行 `php artisan migrate --force`，再构建前端、刷新配置/路由/视图缓存。修改初始管理员密码通过此页面进行，不通过 .env 的 ADMIN_PASSWORD 覆盖已有账号。
